# Uso de Cookiecutter

El repositorio incluido sigue un esqueleto de proyecto Python empaquetado (src/, tests/, docs/, pyproject.toml, .github/). El archivo `cookiecutter.json` documenta variables de plantilla, pero **no demuestra que el proyecto haya sido generado originalmente mediante Cookiecutter**. Para satisfacer la evidencia estricta de la consigna, regenerar el esqueleto desde una plantilla Cookiecutter real y registrar el comando y salida en el informe, o adjuntar evidencias del proyecto inicial preexistente si efectivamente se creó así.
